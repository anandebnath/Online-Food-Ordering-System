# 🍔 Online Food Ordering System

Full A-to-Z project using **HTML, CSS, JavaScript, Node.js (Express)** and **JSON files as database**. No PHP, No MySQL/XAMPP needed.

## Project Structure
```
Food-Ordering-System/
├── backend/
│   ├── data/
│   │   ├── foods.json
│   │   ├── users.json
│   │   └── orders.json
│   ├── db.js
│   ├── server.js
│   └── package.json
├── frontend/
│   ├── css/style.css
│   ├── js/ (script.js, menu.js, auth.js, cart.js, admin.js)
│   ├── index.html
│   ├── login.html
│   ├── register.html
│   ├── cart.html
│   ├── order-success.html
│   └── admin.html
└── README.md
```

## Run the project
```bash
cd backend
npm install
npm start
```
